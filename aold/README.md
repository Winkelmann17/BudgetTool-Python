# WinkelBudget 0.5.1
Hello! This is the repo for the WinkelBudget application!  
  
**NOTE: THIS APPLICATION IS IN ALPHA, IT IS NOT IN IT'S FINAL STATE. IF THERE ARE ANY BUGS PLEASE LET ME KNOW SO THAT I CAN FIX THEM APPOPRIATELY**  
  
This budget application can he,lp you keep track of your spending on a monthly basis while also giving a fun, unique user interface. This application makes use of Python's many other capabilities to provide a unqiue blend of charts, graphts, and tables to give a fantastic budget overview experience.  

## How To Get Started
1. Install Python 3.10 or later.
2. Download or clone this repo to your desired location
3. Navigate to the folder named *BudgetTool*
4. Install the dependencies by running: *pip install -r requirements.txt*
5. Run the application with *python core.py*

## Inspiration for WinkelBudget
Personally, I wanted to make this application to give myself a tool to budget effectively with all the bells and whistles of other applications (that often require a payment). In doing so, I've also been able to grow in my ability to develop complex programs. Application programming is not something I do in my regular time.
